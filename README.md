# Teoria do Crime

Material de estudo de Direito Penal (Teoria do Crime) para o bacharelado em Direito: propedêutica, norma penal, lei penal no tempo, no espaço e em relação às pessoas, teoria do crime, conduta e nexo causal, dolo e culpa, iter criminis, tipicidade, ilicitude, culpabilidade, teoria do erro e concurso de pessoas. Inclui glossário com busca e simulado com 124 questões comentadas.

Página única (`index.html`), sem dependências de build. Para publicar no GitHub Pages: envie `index.html` para a raiz do repositório e ative *Settings → Pages → Deploy from a branch → main / (root)*.

## Fontes
Código Penal (DL 2.848/1940, compilado), Código de Processo Penal (DL 3.689/1941), Constituição Federal de 1988, Lei 15.517/2026, Lei 13.445/2017, Anteprojeto de Código Penal (PLS 236/2012) e jurisprudência do STF e do STJ, conferidos nos sites oficiais.
